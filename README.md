## About

This module introduces the fundamentals of Java programming. Participants will learn to create and execute Java files using the command line and will be guided through the process of writing the `main()` method, which is essential for running Java programs.

## Content

| Lesson                                                                 | Time   | Skills                                       |
|------------------------------------------------------------------------|--------|----------------------------------------------|
| [What is Java?](./what-is-java/README.md)                              | 10 min | Learn what Java is and why it's used.        |
| [Setup](./setup/README.md)                                             | 5 min  | Setup the development environment.           |
| [Writing Your First Java App](./writing-your-first-java-app/README.md) | 25 min | Create a Java application.                   |
| [Running Your First Java App](./running-your-first-java-app/README.md) | 10 min | Run a Java file from the command line.       |
| [Variable Initialization](./variable-initialization/README.md)         | 20 min | Declare variables with primitive data types. |
| **Total content**                                                      | 70 min |                                              |
