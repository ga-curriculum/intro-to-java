## Version 1.0 - Updates from legacy content

This release modularizes the legacy [my-first-java](https://git.generalassemb.ly/ENT-JAVA-Accelerator/my-first-java) lecture and provides some other minor updates detailed below. Updates are provided here at the module level, but all subsequent updates should be documented at the lesson level.

### Release details

#### Additions

- Add the **What is Java** microlesson

#### Changes

- Tune content for a global audience
- Setup is done in IntelliJ instead of cloning a repo
- Students now use the IntelliJ terminal for some actions
- Content copy edit pass

#### Removals

- None
