## Lecture tips

In this lecture students will write and run their first Java app in IntelliJ.

Point out features of the IDE as you work with it, it could be student's first time writing code in it. To this point - a quick pulse check of your classroom to get a sense of people's familiarity with Java/IntelliJ so that you're able to appropriately contextualize the content to their existing skills.

Consider writing the `HowdyPartner` class and the `main()` method signature on a whiteboard so you can underline and point to things (modifiers, parameters) as you go.

## Activity solutions

### [Writing Your First Java App](../writing-your-first-java-app/README.md)

Students are asked to do some research and write a line of code that will print `Howdy, Partner!` to the console. This is the solution:

```java
public class HowdyPartner {
    public static void main(String[] args) {
        System.out.println("Howdy, Partner!");
    }
}
```
